# batch-url-tester
A user-friendly GUI tool built with Python/Tkinter for batch testing the accessibility of web URLs.

## Core Features
✅ Batch URL accessibility detection (support HTTP/HTTPS, GET/POST/HEAD methods)
✅ Concurrent request processing (customizable thread count)
✅ Flexible configuration (timeout control, redirect following, request retries)
✅ Rich error feedback (timeout/connection failure/SSL error, etc.)
✅ Result export (CSV/JSON format)
✅ Thread-safe GUI updates (no crash during concurrent execution)
✅ Cross-platform support (Windows/macOS/Linux)

## 核心功能
