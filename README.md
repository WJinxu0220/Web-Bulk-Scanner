# web批量访问器
一个使用Python/Tkinter构建的用户友好的GUI工具，用于批量测试web url的可访问性。

##核心功能
✅批量URL可访问性检测（支持HTTP/HTTPS， GET/POST/HEAD方法）
✅并发请求处理（可自定义线程数）
✅灵活的配置（超时控制、重定向跟踪、请求重试）
✅丰富的错误反馈（超时/连接失败/SSL错误等）
✅结果导出（CSV/JSON格式）
✅线程安全的GUI更新（在并发执行期间不会崩溃）
✅跨平台支持（Windows/macOS/Linux）
